# 行为观察记录

目前没有本项目实际运行证据。以下是后续获准运行时的观察目标，不是本轮执行过的检查。禁止以源码存在、锁文件生成或界面相似记为验证。

| 模块 | 观察动作 | 需记录的结果 |
| --- | --- | --- |
| 核心 | 两资料、普通/私密窗口，导航/后退/关闭/重开/退出恢复 | URL、标题、顺序、导航记录、Cookie隔离；私密重启不恢复 |
| 分组 | 建组、拖入拖出、折叠、选中成员、固定、重启 | 组名/颜色/成员顺序和恢复一致；失败不写假状态 |
| 收藏 | 当前页星标、目录移动、搜索、删除，重启 | 真实事务/查询；私密显式收藏写所属资料 |
| 历史 | 导航/同页/标题更新、日期搜索、分页清理 | 导航去重、事务更新、私密不写 |
| 下载 | 路径选择、暂停/继续/取消、断网/重启 | 文件与状态一致；恢复条件不足显示失败 |
| 权限/密码 | 子frame请求、记住/撤销；提交表单保存与再次填充 | 真实origin、用户决定、密文持久、私密边界 |
| 新页/工具 | 背景导入、快捷项、阅读、截图、导航中取消 | 持久化、取消旧结果、原页面可恢复 |
| 翻译/Leo | 资格与配置、内容授权、完成/取消/错误 | 请求范围与状态真实、秘密不进日志 |
| Shields | 固定规则版本下阻断/例外/重定向/CSP/页面过滤 | 引擎版本与具体决策；更新失败保留旧版 |
| 扩展 | 安装/更新权限确认、action/popup、卸载/重启 | 隔离Session/页面与资源释放；网络差异明确 |

Native或系统组件运行前按对应证据计划记录：固定版本、架构、产物来源/哈希、实际加载路径、成功与失败判据、回滚版本。失败只回传必要错误和版本信息，不含密码、token或私密浏览数据。
